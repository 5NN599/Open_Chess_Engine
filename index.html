Features

Alpha-beta search

Iterative deepening with a transposition table, null-move pruning, late-move reductions, singular extensions and a quiescence search.

Game review

Paste a PGN, FEN or move list. Each move is rated from best move to blunder, with accuracy scores, an evaluation graph and the better move drawn on the board.

Uses every CPU core

Game review analyzes positions on all cores at once. Live analysis can search with several threads that share one hash table.

Seven playing levels

From a relaxed beginner game to full strength, with adjustable think time.

Easy to read and change

Plain JavaScript with no build step and no dependencies. Search constants and evaluation terms sit in single, commented files.

MIT licensed

Use it, fork it or embed it in your own project. Contributions are welcome on GitHub.

How it works

  1. Play

    Pick a side and a strength, then move the pieces by dragging or clicking. The evaluation bar shows who is better.

  2. Analyze

    Switch to the analysis board to see the engine's best lines for any position, up to the depth you choose.

  3. Review

    Paste a finished game and press Analyze game. Step through it to see mistakes, blunders and what you should have played.

Frequently asked questions

What is Open Chess Engine?

A free, open-source chess engine with a built-in analysis board and game reviewer. You can play against it, analyze any position and review a PGN game.

How do I review a game?

Paste a PGN, a list of moves or a FEN into the Game review box and press Analyze game. You can also open a .pgn file.

How strong is the engine?

Strength depends on your device and the think time. It is a classical alpha-beta engine with a hand-written evaluation, so it does not match the strongest engines such as Stockfish.

Can I run it myself?

Yes. Download the repository and serve the folder with any static web server, for example python3 -m http.server. There is nothing to build.

How do I contribute?

Open an issue or a pull request on GitHub. Ideas for the evaluation, the search or the interface are all welcome.
